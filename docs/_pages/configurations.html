Sysmon Configuration Files

ICS Watch Dog provides Sysmon configurations that progress from enterprise IT baseline through ICS/OT-specific monitoring. All configs are built from scratch and mapped to the SANS ICS 5 Critical Controls. Download from the ICS Watch Dog GitHub repository.

Choosing a Configuration

Situation Recommended Config
First time deploying Sysmon on any Windows system IT Baseline
Legacy Windows in OT (Server 2008/2012, Win 7/10 LTSC) IT Baseline or OT Baseline (both schema 4.50)
OT environment, ready for ICS-specific monitoring OT Baseline
Established OT monitoring, want broader coverage OT Enhanced
Experienced team, role-specific tuning OT Advanced
Only need file creation monitoring Community: File Create Only
Learning Sysmon, want a well-known reference Reference: SwiftOnSecurity

Tuning required: All configurations are starting points. Administrators MUST tune these configs for their specific environments. Test in a non-production environment before deploying to production systems. See Getting Started for deployment guidance.

Curated Configurations

These configs are maintained by the ICS Watch Dog project and follow a progressive structure. Each builds on the previous, adding capabilities as your monitoring program matures.

IT Baseline

Status: In Development
Minimum Sysmon: v13+ (schema 4.50)
SANS Controls: #1 (Incident Response), #4 (Secure Remote Access), #5 (Vulnerability Management)

Enterprise IT starting point for any Windows system. General-purpose monitoring covering process creation, network connections, file creation, and registry changes. Includes detection of known remote access tools (TeamViewer, AnyDesk, VNC, ScreenConnect, and others) per CISA/NSA guidance. This is explicitly an IT-focused configuration -- it does not include OT-specific rules.

Best for: Teams deploying Sysmon for the first time on any Windows system. Start here.

OT Baseline

Status: In Development
Minimum Sysmon: v13+ (schema 4.50)
SANS Controls: #1, #2 (Defensible Architecture), #3 (Network Visibility), #4, #5

Builds on the IT Baseline with OT-specific additions. Adds monitoring examples for major ICS/OT vendor software (Siemens, Rockwell, Schneider Electric, AVEVA/OSIsoft PI, Ignition, SEL), ICS-relevant file type monitoring, and adjusted exclusions for OT environments. Vendor-specific rules are examples that must be validated against your actual installations.

Best for: OT environments ready for ICS-specific endpoint monitoring.

OT Enhanced

Status: In Development
SANS Controls: #1, #2, #3, #4, #5

Broader OT coverage including network connection monitoring for industrial ports (Modbus TCP/502, EtherNet/IP/44818, OPC-UA/4840, DNP3/20000, S7comm/102). Detects which processes connect to these ports -- useful for identifying unauthorized access. May use newer Sysmon schema features.

Best for: Teams with established monitoring looking to increase visibility into OT network activity.

OT Advanced

Status: In Development
SANS Controls: #1, #2, #3, #4, #5

Advanced monitoring leveraging newer Sysmon features (FileBlockExecutable, FileExecutableDetected). Provides role-specific customization guidance for HMI stations, engineering workstations, historians, and other OT system roles. Developed further as the project matures.

Best for: Experienced teams ready for comprehensive, role-specific endpoint monitoring.

Community Configurations

Community-contributed configurations for specific use cases. These are not maintained or tested by Cutaway Security, LLC. Users must perform their own review and testing before deployment.

File Create Only

Author: Aaron Boyd (icsblitz)
Minimum Sysmon: v13+ (schema 4.50)

Monitors file creation events, tracking dangerous attachment types, scripts, executables, and other files of interest. Useful for environments where file creation monitoring is the immediate priority.
