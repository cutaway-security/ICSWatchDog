# ICS Watch Dog

![ICS Watch Dog Logo](/assets/images/icswatchdog_logo_0_250x250.png){: width="150" }

[Microsoft Sysinternals Sysmon](https://learn.microsoft.com/en-us/sysinternals/downloads/sysmon) is one of the best tools for improving visibility into what happens on your Windows servers and workstations. But for many ICS/OT teams, Sysmon's configuration files are complex and intimidating -- especially for Windows administrators who haven't worked with them before.

**ICS Watch Dog** provides ready-to-use Sysmon configurations designed for industrial and critical infrastructure environments. Start with a simple configuration, then grow into more advanced monitoring as your program matures.

## Why ICS Watch Dog?

- **Built for ICS/OT** -- Configurations designed with industrial environments in mind, not just enterprise IT
- **Tiered approach** -- Start simple (Tier 1) and advance at your own pace through increasingly detailed monitoring
- **Legacy OS support** -- Starter and baseline configs use Sysmon schema 4.50 for compatibility with older Windows versions common in OT environments
- **No SIEM required** -- Useful even if you only have Windows Event Viewer, though configs work with centralized logging and SIEMs too
